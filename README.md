# Gravity Flip

A neon arcade browser game built by an AI coding agent (Claude Code) from a one-sentence prompt, for the MadeInMinutes YouTube channel.

**Play:** https://ematrix911.github.io/gravity-flip/

Controls: Space / Up / tap to flip gravity. Collect orbs for combos, grab the violet orb for a shield.

Prompt: *Build a neon arcade browser game where you flip gravity to dodge obstacles, with combos, a shield power-up, sound effects and a high score, all in a single HTML file.*
